# Ladies Apparel Sales POS

Self-contained web app: inventory inward, multi-item POS cart, live stock,
profit tracking, customer history, and CSV exports. Data stored locally on
the device — works offline after first load.

To deploy as a real Android .apk: host this folder (e.g. GitHub Pages or
Netlify Drop), then run the URL through pwabuilder.com to generate a signed
installable APK. See the chat response for exact steps.
